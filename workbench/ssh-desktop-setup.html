Claude デスクトップから Linux へつなぐ手順

更新日: 2026-11-23

  • 目的: Windows の Claude デスクトップから SSH で Linux（172.17.1.3）につなぎ、Linux の作業場と Claude Code で開発する。
  • 流れ: 1. 用意する（Claude を入れる・Linux に 1 回つなぐ） → 2. デスクトップの設定 → 3. つなぐ先を登録 → 4. リポジトリごとの環境 → 5. hello で確かめる。1〜3 は各自 1 回、4〜5 はリポジトリごと。
  • 読み方: 絵の 赤丸 の所を押す・打つ。打つ物は灰色の枠からそのまま写す。「利用者名」「リポジトリ名」は自分のものに変える。破線の枠の歩は、写真をまだ撮っていない歩。

1. 始める前に用意すること

各自の Windows で 1 回だけ。

  1. 1-1管理者から 3 つをもらう

    始める前に、管理者から次の 3 つをもらう。

    • 利用者名とパスワード: Linux（172.17.1.3）にログインするときの物。以下では「利用者名」と書く。
    • API キー: Amazon Bedrock の API キー。2-3 で入れる。
    • リポジトリ: Linux の /home/<利用者名>/REPOS/ の下に、使うリポジトリが置いてあること。無いときは管理者に聞く。

  2. 1-2Claude デスクトップを入れる

    ブラウザで次を開き、Windows 用をダウンロードする。

    https://claude.com/download

    ダウンロードした Claude Setup.exe を開く。「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」を押す。

    Microsoft Store の Claude は使わない。ストア版は、SSH のパスワードの画面が出せないことがある。

    もう入っている人は、☰ → ヘルプ → Claude について で版を見る。SSH でつなぐ機能は 新しい版 にしか無い（この手順は 5.1231.2 で確かめた）。古ければ「アップデートを確認...」で上げる。

    写真はまだ無い: 撮る画面——ダウンロードの頁と、入れる途中の許可の画面。画面の言葉は、写真で確かめるまで未確認。

  3. 1-3Windows の ssh の版を確かめる

    スタートボタンを押し、cmd と打って Enter を押す。コマンドプロンプトが開く。

    次を打ち、OpenSSH_for_Windows_9.4 以上（例 OpenSSH_for_Windows_9.5p1）と出れば良い。

    ssh -V

    9.4 より古い版（例 8.x）でも、次の 1-4 をやれば進める。古い版だと、デスクトップは自分の中の SSH でつなぎ、3-6 の確認の画面を出さないため、1-4 で先につなぐ先を覚えさせておく。何も出ないとき（ssh が無いとき）は、管理者に知らせる。

  4. 1-4Linux に 1 回つないでおく

    同じコマンドプロンプトで次を、利用者名を自分のものに変えて打つ。

    ssh 利用者名@172.17.1.3

    初めてなら Are you sure you want to continue connecting (yes/no/[fingerprint])? と出る。yes と打って Enter を押す。

    パスワードを聞かれたら入れる。打っても字は出ないが、そのまま Enter を押す。

    ログインできたら次を打ち、使うリポジトリの名前が出るのを見る。

    ls ~/REPOS

    見終わったら次を打って抜ける。これで、Windows が つなぐ先を覚えた状態になる。

    exit

2. デスクトップの設定（サードパーティ推論の設定）

各自の Windows で 1 回だけ。

  1. 2-1サインインせずに開発者モードを入れる

    Claude を開くと、サインインの画面が出る。サインインしない（Anthropic のアカウントは作らない）。

    左上の ☰ → ヘルプ → トラブルシューティング → 開発者モードを有効にする を押す。☰ に「開発者」が出れば良い。もう出ている人は飛ばす。

    写真はまだ無い: 撮る画面——サインインの画面と、☰ → ヘルプ → トラブルシューティングのメニュー。画面の言葉は、写真で確かめるまで未確認。

  2. 2-2設定の窓を開く

    左上の ☰ → 開発者 → サードパーティ推論を設定... を押す。

  3. 2-3Bedrock とつなぐ

    左の「接続」を押す。推論の提供元に Amazon Bedrock を選ぶ。

    地域（リージョン）に ap-northeast-1（東京）を、API キーの欄に 1-1 でもらったキーを入れる。

    Linux で動く Claude は、ここに入れたキーだけを使う。Linux 側に置いたキーは使わない。

    写真はまだ無い: 撮る画面——「接続」の上の方——提供元・地域・API キーの欄。画面の言葉は、写真で確かめるまで未確認。

  4. 2-4SSH でつないでよい先を許す

    窓の左上の「設定を検索」に SSH と打つ。出てきた「SSH ホスト許可リスト」の欄に次を打って Enter を押す。欄に 172.17.1.3 の札が付けば良い。

    172.17.1.3

  5. 2-5モデルを Linux の CLI とそろえる

    検索の欄を空にし、左の「接続」を押して下へ送る。「利用可能な場合は常に 1M を使用」をオンにし、「モデルリスト」の「＋ 追加」で次の 3 つを この順に 1 つずつ足す（最初の 1 つが既定になる）。

    global.anthropic.claude-opus-5-5
    global.anthropic.claude-sonnet-5-5
    global.anthropic.claude-haiku-5-5

  6. 2-6適用して再起動する

    右下の「変更を適用」を押し、出てきた確認で 保存して再起動 を押す。

  7. 2-7いま入れた設定で始める

    再起動すると、またサインインの画面が出る。Anthropic のサインインではなく、いま入れた設定で始めるほうを押す。

    後で設定を直すときに ☰ の「開発者」が無ければ、2-1 の開発者モードをもう一度入れる。

    写真はまだ無い: 撮る画面——再起動した後のサインインの画面。画面の言葉は、写真で確かめるまで未確認。

3. つなぐ先を登録する

各自 1 回だけ。ここで登録するのは「どの機械に、誰としてつなぐか」だけ。

  1. 3-1環境の一覧を開く

    上の </>（Code）のタブを開き、真ん中の 環境を選択 を押す。

  2. 3-2新しい環境の画面を開く

    一覧のいちばん下の「＋ 新しい環境」を押す。

  3. 3-3ホストの一覧を開く

    上の SSH のタブを押し、「ホスト」の欄を押す。名前の欄はまだ空のままでよい。

  4. 3-4つなぐ先を足す画面を開く

    一覧の「＋ SSH 接続を追加...」を押す。

  5. 3-5つなぐ先を書く

    「名前」に、つなぐ先の名前（例 Linux AI サーバー）を打つ。「SSH ホスト」に次を、利用者名を自分のものに変えて打つ。ポート・SSH 鍵・ワークツリーフォルダは 空のまま。右下の「SSH 接続を追加」を押す。

    利用者名@172.17.1.3

  6. 3-6つなぐことを許す

    「SSH ホストに接続しますか？」と出たら、つなぐ先が合っているのを見て 連携/連携させる を押す。パスワードを聞かれたら、自分で入れる。

4. リポジトリごとの環境を作る

使うリポジトリ 1 つにつき 1 回。3. の続きなら、もう「新しい環境」の画面にいる。別のときは 3. の 1〜2 で「新しい環境」の画面を開く。

  1. 4-1名前とつなぐ先を入れる

    SSH のタブで、「名前」に リポジトリ名（例 workbench）を打つ。左の一覧にこの名前で出る。「ホスト」で 3. で足したつなぐ先を選ぶ。

  2. 4-2フォルダを選ぶ画面を開く

    「フォルダ」の 選択... を押す。Linux のフォルダの一覧が出れば、SSH でつながっている。

  3. 4-3リポジトリのフォルダを選ぶ

    上の欄にリポジトリのフォルダを打って「移動」を押す（一覧をたどってもよい）。欄が合っているのを見て「フォルダーを選択」を押す。

    /home/<利用者名>/REPOS/リポジトリ名

  4. 4-4環境を作る

    右下の 環境を作成 を押す。「環境変数」は何も書かない。

  5. 4-5フォルダを信頼する

    「このワークスペースを信頼しますか？」と出たら、フォルダとつなぐ先が合っているのを見て「ワークスペースを信頼」を押す。

5. 動くか確かめる

環境を作るたびに 1 回。

  1. 5-1hello を送る

    Code のタブで、入力欄の下に作った環境の名前が出ているのを見て、hello と送る。返事が来れば 完了。右下のモデルが Opus 5.5 などになっていることも見る。

    初めての 1 回は、デスクトップが Linux に自分のエンジンを置くので、少し時間がかかる。何分待っても返事が無いときは、まず 2-3 の API キーを見直す。それでも来ないときは、管理者に知らせる。

間違えやすい所

  • 環境の名前: 環境の名前は リポジトリ名 にする。つなぐ先の名前（3.）とは別の物で、左の一覧にはこちらが出る。
  • 一覧の SSH: 環境の一覧の「SSH」には、つなぐ先（下に 利用者名@172.17.1.3 と出る行）と、環境（リポジトリ名の行）が並ぶ。2 つ出るのは正しい。
  • プロキシ: デスクトップの設定の「プロキシサーバーの URL」と、環境の「環境変数」には 何も書かない。Linux 側の外への通信は管理者が設定してある。
  • モデル: 「モデルリスト」を書かないと、東京の Bedrock から自動で拾った 古いモデル しか選べない。2. の 5 は飛ばさない。
  • 環境は 1 リポジトリに 1 つ: つなぐ先を直に選んでセッションを始めることは できない。使うリポジトリごとに 4. で環境を作る。フォルダの選び始めの場所は決められないので、4. の 3 では上の欄にフォルダを直に打つのが早い。
  • 名前の欄: 3. の 3 で開く「新しい環境」の画面の名前は、つなぐ先を足した後に 4. の 1 で入れる。3. の時点で名前を入れない。
